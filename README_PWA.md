# CapView Plus — PWA instalável

Este pacote já está pronto para GitHub Pages.

## Como publicar

1. Suba todos os arquivos deste pacote na raiz do repositório.
2. No GitHub, vá em:
   Settings → Pages → Deploy from branch
3. Selecione:
   Branch: main
   Folder: /root
4. Abra a URL publicada pelo GitHub Pages.
5. No Edge/Chrome, clique no ícone de instalar ao lado da barra de endereço.

## Observações

- O botão de instalar só aparece em HTTPS ou localhost.
- Abrindo por file:// o Service Worker/PWA não funciona.
- O app continua sendo o CapView local, mas agora pode abrir em modo app e funcionar com cache offline.
