# ORIZON

ORIZON é uma PWA local para planejamento de capacidade, demandas, apontamentos, janelas livres, horas extras, execução diária e sincronização de base de dados.

## Guia operacional

O guia principal para usuários está em:

- [docs/IT_HOW_TO_USE_ORIZON.md](docs/IT_HOW_TO_USE_ORIZON.md)

Ele reúne:

- IT/Instrução de Trabalho.
- How to use por aba.
- Cenários práticos.
- Norte de decisão para usuários, gestores e PMO/admin.

## Execução local simples

Como o app é estático, você pode abrir `index.html` diretamente ou servir a pasta com um servidor HTTP local:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.
